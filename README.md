# Bohdan's Blog powered by Next.js

I became very concerned about choosing the right CMS for my blog, so 
I've decided to create my own simplified CMS for a blog.
It won't have that many feature an actual headless CMS would, but 
I hope it'll cover the basics.

This is a great playground to use [`shadcn ui`](https://ui.shadcn.com/) library that I never used. 
As well to play around with latest [`Next.js`](https://nextjs.org/) version and utilize its SSG functionality for articles.
